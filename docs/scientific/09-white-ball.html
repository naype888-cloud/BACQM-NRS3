B9 · Boundary light below capacity, and layered boundaries

Let X be a finite set of boundary steps, Config X = 𝒫(X) and capacity X = |X| log 2, so that Hₛ d ≤ capacity X for every distribution d on Config X, with equality iff d is uniform (BoundaryBits.saturated_iff_uniform). Two hypotheses are declared as structures and shown satisfiable; the layer counting is proved outright.
